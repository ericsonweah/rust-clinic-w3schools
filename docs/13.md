# 🛠 Step 1 — Middleware type

We define middleware as a function that:

* Receives the `HttpRequest`.
* Has access to `next`, the next middleware/route handler.
* Returns an `HttpResponse`.

```rust
pub type Middleware = Box<dyn Fn(HttpRequest, &dyn Fn(HttpRequest) -> HttpResponse) -> HttpResponse + Send + Sync>;
```

---

# 🛠 Step 2 — Update `App`

We add a `middlewares` vector to `App` and a `.use()` method:

```rust
pub struct App {
    routes: Arc<Vec<(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)>>,
    middlewares: Arc<Vec<Middleware>>,
}

impl App {
    pub fn new() -> Self {
        Self {
            routes: Arc::new(Vec::new()),
            middlewares: Arc::new(Vec::new()),
        }
    }

    pub fn use<F>(&mut self, mw: F)
    where
        F: Fn(HttpRequest, &dyn Fn(HttpRequest) -> HttpResponse) -> HttpResponse + Send + Sync + 'static,
    {
        Arc::get_mut(&mut self.middlewares).unwrap().push(Box::new(mw));
    }
}
```

---

# 🛠 Step 3 — Middleware chaining logic

We fold middlewares around the route dispatcher, so they execute in order:

```rust
fn run_middlewares(
    req: HttpRequest,
    middlewares: &[Middleware],
    final_handler: &dyn Fn(HttpRequest) -> HttpResponse,
) -> HttpResponse {
    if middlewares.is_empty() {
        return final_handler(req);
    }

    let (first, rest) = middlewares.split_first().unwrap();
    let next = |r: HttpRequest| run_middlewares(r, rest, final_handler);
    first(req, &next)
}
```

# 🛠 Step 4 — Integrate into `handle_connection`

Replace the direct route call with a middleware chain:

```rust
let response = if parts.len() >= 2 {
    let method = parts[0];
    let path = parts[1];

    let mut resp = res::not_found("404 Not Found");

    let middlewares = routes_and_middleware.1.clone(); // from App
    for (m, pattern, handler) in routes_and_middleware.0.iter() {
        if m == method {
            if let Some(params) = match_route(pattern, path) {
                let req = HttpRequest {
                    path: path.into(),
                    params,
                };
                let final_handler = |r: HttpRequest| handler(r);
                resp = run_middlewares(req, &middlewares, &final_handler);
                break;
            }
        }
    }
    resp
} else {
    res::not_found("400 Bad Request")
};
```

# ✅ Example Usage

```rust
fn main() {
    let mut app = App::new();

    // Middleware
    app.use(|req, next| {
        println!("[LOG] {}", req.path);
        next(req) // pass to next middleware or route
    });

    // Routes
    app.get("/", |_req| {
        res::ok("Welcome to RawExpress with middleware!")
    });

    app.get("/secret", |_req| {
        res::ok("Top Secret!")

}
```
