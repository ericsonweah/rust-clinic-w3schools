```rust
app.get("/users/:id", |req| {

});
```

Just like in Express.

## 🛠 Step 1 — Define `HttpRequest` with params

Add a simple struct to hold request info and extracted params:

```rust
#[derive(Debug, Clone)]
pub struct HttpRequest {
    pub path: String,
    pub params: HashMap<String, String>,
}
```

---

## 🛠 Step 2 — Update `App` routing

Instead of storing routes as plain strings (`GET /path`), store **patterns** and match them at runtime:

```rust
pub struct App {
    routes: Arc<Vec<(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)>>,
}
```

* The `String, String` pair is `(method, pattern)`.
* Example: `( "GET", "/users/:id" )`.

---

## 🛠 Step 3 — Route matching with params

Add a helper to check if a request path matches a route pattern:

```rust
fn match_route(pattern: &str, path: &str) -> Option<HashMap<String, String>> {
    let pat_parts: Vec<&str> = pattern.trim_matches('/').split('/').collect();
    let path_parts: Vec<&str> = path.trim_matches('/').split('/').collect();

    if pat_parts.len() != path_parts.len() {
        return None;
    }

    let mut params = HashMap::new();
    for (p, a) in pat_parts.iter().zip(path_parts.iter()) {
        if p.starts_with(':') {
            params.insert(p[1..].to_string(), a.to_string());
        } else if p != a {
            return None;
        }
    }
    Some(params)
}
```

## 🛠 Step 4 — Adjust handler signature

Handlers now receive `HttpRequest` instead of raw `&str`:

```rust
pub fn get<F>(&mut self, path: &str, handler: F)
where
    F: Fn(HttpRequest) -> HttpResponse + Send + Sync + 'static,
{
    Arc::get_mut(&mut self.routes).unwrap().push((
        "GET".into(),
        path.into(),
        Box::new(handler),
    ));
}
```

---

## 🛠 Step 5 — Update connection handling

Parse path and try to match against registered routes:

```rust
fn handle_connection(
    mut stream: TcpStream,
    routes: Arc<Vec<(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)>>,
) {
    let mut buffer = [0; 512];
    let _ = stream.read(&mut buffer);

    let req_str = String::from_utf8_lossy(&buffer);
    let mut lines = req_str.lines();
    let request_line = lines.next().unwrap_or("");
    let parts: Vec<&str> = request_line.split_whitespace().collect();

    let response = if parts.len() >= 2 {
        let method = parts[0];
        let path = parts[1];

        let mut resp = res::not_found("404 Not Found");
        for (m, pattern, handler) in routes.iter() {
            if m == method {
                if let Some(params) = match_route(pattern, path) {
                    let req = HttpRequest {
                        path: path.into(),
                        params,
                    };
                    resp = handler(req);
                    break;
                }
            }
        }
        resp
    } else {
        res::not_found("400 Bad Request")
    };

    let resp_str = response.to_string();
    let _ = stream.write_all(resp_str.as_bytes());
    let _ = stream.flush();
}
```

## ✅ Full Example

```rust
let mut app = App::new();

app.get("/", |_req| {
    res::ok("Welcome to RawExpress with params!")
});

app.get("/users/:id", |req| {
    res::ok(&format!("User ID is {}", req.params["id"]))
});

app.listen("127.0.0.1:3000").unwrap();
```
