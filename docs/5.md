Perfect 🚀 — time to add **middleware support with `next()`**, so your RawExpress prototype can do things like:

```rust
app.use(|req, next| {
    println!("[LOG] {} {}", req.method, req.path);
    next(req)
});
```

…and multiple middlewares will chain together before reaching the route handler, just like Express.

---

# 🛠 Step 1 — Update `HttpRequest`

We’ll add `method` and keep `params`:

```rust
#[derive(Debug, Clone)]
pub struct HttpRequest {
    pub method: String,
    pub path: String,
    pub params: HashMap<String, String>,
}
```

---

# 🛠 Step 2 — Define Middleware type

A middleware is a function that takes `HttpRequest` and a `next` callback, then returns `HttpResponse`.

```rust
type Next<'a> = &'a dyn Fn(HttpRequest) -> HttpResponse;
type Middleware = Box<dyn Fn(HttpRequest, Next) -> HttpResponse + Send + Sync>;
```

---

# 🛠 Step 3 — Update `App` struct

We need to store both **middlewares** and **routes**:

```rust
pub struct App {
    routes: Arc<Vec<(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)>>,
    middlewares: Arc<Vec<Middleware>>,
}
```

---

# 🛠 Step 4 — Add `use` method

Allow registering middlewares:

```rust
impl App {
    pub fn use_middleware<F>(&mut self, mw: F)
    where
        F: Fn(HttpRequest, Next) -> HttpResponse + Send + Sync + 'static,
    {
        Arc::get_mut(&mut self.middlewares).unwrap().push(Box::new(mw));
    }
}
```

---

# 🛠 Step 5 — Middleware execution pipeline

When a request comes in:

1. Run middlewares in order.
2. If no middleware short-circuits, continue to route handler.

```rust
fn run_pipeline(
    req: HttpRequest,
    mws: &[Middleware],
    routes: &[(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)],
) -> HttpResponse {
    if let Some((first, rest)) = mws.split_first() {
        let next: Next = &|req2: HttpRequest| run_pipeline(req2, rest, routes);
        first(req, next)
    } else {
        // Route matching
        for (m, pattern, handler) in routes.iter() {
            if m == &req.method {
                if let Some(params) = match_route(pattern, &req.path) {
                    let mut new_req = req.clone();
                    new_req.params = params;
                    return handler(new_req);
                }
            }
        }
        res::not_found("404 Not Found")
    }
}
```

# 🛠 Step 6 — Update `handle_connection`

Use the pipeline:

```rust
fn handle_connection(
    mut stream: TcpStream,
    routes: Arc<Vec<(String, String, Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>)>>,
    middlewares: Arc<Vec<Middleware>>,
) {
    let mut buffer = [0; 512];
    let _ = stream.read(&mut buffer);

    let req_str = String::from_utf8_lossy(&buffer);
    let mut lines = req_str.lines();
    let request_line = lines.next().unwrap_or("");
    let parts: Vec<&str> = request_line.split_whitespace().collect();

    let response = if parts.len() >= 2 {
        let method = parts[0].to_string();
        let path = parts[1].to_string();
        let req = HttpRequest {
            method,
            path,
            params: HashMap::new(),
        };
        run_pipeline(req, &middlewares, &routes)
    } else {
        res::not_found("400 Bad Request")
    };

    let resp_str = response.to_string();
    let _ = stream.write_all(resp_str.as_bytes());
    let _ = stream.flush();
}
```

# ✅ Example Usage

```rust
fn main() {
    let mut app = App::new();

    // Middleware 1: logger
    app.use_middleware(|req, next| {
        println!("[LOG] {} {}", req.method, req.path);
        next(req)
    });

    // Middleware 2: block a path
    app.use_middleware(|req, next| {
        if req.path == "/blocked" {
            res::not_found("This path is blocked")
        } else {
            next(req)
        }
    });

    // Routes
    app.get("/", |_req| {
        res::ok("Welcome to RawExpress with middleware!")
    });

    app.get("/users/:id", |req| {
        res::ok(&format!("User ID: {}", req.params["id"]))
    });

    app.listen("127.0.0.1:3000").unwrap();
}
```
