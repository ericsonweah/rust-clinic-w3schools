# 🛠 Step 1 — Change Handler & Middleware Signatures

Currently:

```rust
type Middleware = Box<dyn Fn(HttpRequest, Next) -> HttpResponse + Send + Sync>;
Box<dyn Fn(HttpRequest) -> HttpResponse + Send + Sync>
```

We need them to return `Future`s. That means using **`Pin<Box<dyn Future<Output = HttpResponse>>>`** (boxed futures).

```rust
use std::future::Future;
use std::pin::Pin;

pub type BoxFuture<T> = Pin<Box<dyn Future<Output = T> + Send>>;

type Next<'a> = &'a dyn Fn(HttpRequest) -> BoxFuture<HttpResponse>;
type Middleware = Box<dyn Fn(HttpRequest, Next) -> BoxFuture<HttpResponse> + Send + Sync>;
type Handler = Box<dyn Fn(HttpRequest) -> BoxFuture<HttpResponse> + Send + Sync>;
```

# 🛠 Step 3 — Add Async `get` / `post`

```rust
impl App {
    pub fn get<F, Fut>(&mut self, path: &str, handler: F)
    where
        F: Fn(HttpRequest) -> Fut + Send + Sync + 'static,
        Fut: Future<Output = HttpResponse> + Send + 'static,
    {
        Arc::get_mut(&mut self.routes)
            .unwrap()
            .push(("GET".into(), path.into(), Box::new(move |req| Box::pin(handler(req)))));
    }

    pub fn post<F, Fut>(&mut self, path: &str, handler: F)
    where
        F: Fn(HttpRequest) -> Fut + Send + Sync + 'static,
        Fut: Future<Output = HttpResponse> + Send + 'static,
    {
        Arc::get_mut(&mut self.routes)
            .unwrap()
            .push(("POST".into(), path.into(), Box::new(move |req| Box::pin(handler(req)))));
    }

    pub fn use_middleware<F, Fut>(&mut self, mw: F)
    where
        F: Fn(HttpRequest, Next) -> Fut + Send + Sync + 'static,
        Fut: Future<Output = HttpResponse> + Send + 'static,
    {
        Arc::get_mut(&mut self.middlewares)
            .unwrap()
            .push(Box::new(move |req, next| Box::pin(mw(req, next))));
    }
}
```

# 🛠 Step 4 — Update Pipeline to Async

```rust
async fn run_pipeline(
    req: HttpRequest,
    mws: &[Middleware],
    routes: &[(String, String, Handler)],
) -> HttpResponse {
    if let Some((first, rest)) = mws.split_first() {
        let next: Next = &|req2: HttpRequest| Box::pin(run_pipeline(req2, rest, routes));
        first(req, next).await
    } else {
        for (m, pattern, handler) in routes.iter() {
            if &req.method == m {
                if let Some(params) = match_route(pattern, &req.path) {
                    let mut new_req = req.clone();
                    new_req.params = params;
                    return handler(new_req).await;
                }
            }
        }
        res::not_found("404 Not Found")
    }
}
```

# 🛠 Step 5 — Run Async Handlers in `handle_connection`

```rust
fn handle_connection(
    mut stream: TcpStream,
    routes: Arc<Vec<(String, String, Handler)>>,
    middlewares: Arc<Vec<Middleware>>,
) {
    let mut buffer = [0; 2048];
    let _ = stream.read(&mut buffer);

    let req = parse_request(&buffer);

    // spawn a new thread to poll the future
    let fut = run_pipeline(req, &middlewares, &routes);

    let response = futures::executor::block_on(fut);

    let resp_str = response.to_string();
    let _ = stream.write_all(resp_str.as_bytes());
    let _ = stream.flush();
}
```

*(Here I’m using `futures::executor::block_on` for simplicity. Later, you’d integrate this into your custom RawExecutor.)*

# ✅ Example Async Usage

### Async Middleware

```rust
app.use_middleware(|req, next| async move {
    println!("[ASYNC LOG] {} {}", req.method, req.path);
    // simulate async work
    tokio::time::sleep(std::time::Duration::from_millis(100)).await;
    next(req).await
});
```

### Async Route

```rust
app.get("/delay", |_req| async move {
    tokio::time::sleep(std::time::Duration::from_secs(1)).await;
    res::ok("Finished after 1 second")
});
```

### Async + Params

```rust
app.get("/users/:id", |req| async move {
    // simulate DB call
    tokio::time::sleep(std::time::Duration::from_millis(200)).await;
    res::ok(&format!("Fetched user {}", req.params["id"]))
});
```
